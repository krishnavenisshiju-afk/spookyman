# 🕷️ Spider-Man Debate: Who is the Best Peter Parker?

An interactive web application where Spider-Man fans can vote for their favorite live-action Peter Parker (Tobey Maguire, Andrew Garfield, or Tom Holland) and participate in a live debate floor.

## 🌐 Live Demo
👉 **[View the Live Debate Website](https://krishnavenisshiju-afk.github.io/spookyman/)**

---

## ✨ Features
* 🗳️ **Interactive Voting:** Cast votes for Tobey, Andrew, or Tom with live vote counters.
* 💬 **Debate Floor:** Post your arguments directly on the site with your name and chosen team.
* 🎨 **Modern Dark UI:** Styled with a sleek, comic-inspired modern design.

---

## 🛠️ Built With
* **HTML5** - Page structure and forms
* **CSS3** - Custom styling and dark theme layout
* **JavaScript (ES6)** - Interactive vote counters and dynamic comment rendering
